## How to use this template

Click **Use this template** on GitHub (or `gh repo create lepetitatelier/<name> --private --template lepetitatelier/project-template`),
then fill in this README and delete the sections that do not apply. Write the project's card in the
[handbook](https://github.com/lepetitatelier/handbook/tree/main/03-projects/cards) first and set its `repo:` field.
Repo name: lowercase, hyphenated, the project's public name.

```
README.md        ← this dashboard: outcome, status, plan, BOM, tests
UPSTREAM.md      ← original sources, authors, licences, versions (if any)
IMPROVEMENTS.md  ← our changes vs upstream (done + backlog)
upstream/        ← pristine originals: NEVER edit
mods/            ← our modified or new designs (CAD, STL, firmware)
docs/            ← build notes, test logs, measurements, photos
```
